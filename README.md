# Exploratory Data Analysis (EDA) using Pandas and NumPy

## 📌 Project Overview

This project demonstrates **Exploratory Data Analysis (EDA)** on the public **Titanic Dataset** using **Python**, **Pandas**, **NumPy**, **Matplotlib**, and **Seaborn**.

The objective is to understand the dataset by generating statistical summaries, identifying missing values, performing basic numerical analysis, and visualizing relationships between numerical features using a correlation heatmap.

---

## 🎯 Objectives

- Load a public tabular dataset
- Explore dataset structure
- Generate descriptive statistics
- Identify missing values
- Perform numerical analysis using NumPy
- Visualize feature correlations
- Save analysis results

---

## 🛠 Technologies Used

- Python 3
- Pandas
- NumPy
- Matplotlib
- Seaborn
